## 架构说明（对审查建议的取舍）

审查建议 NormalizedNode 稳定输出后去掉对原始 XML 的依赖。实现上保留了 `raw` 字段：
P0 计划硬性要求「原始 EXML 属性必须可追溯」（native.tag/attributes 直接来自 raw）。
实际采取的边界是：**归一化层**（URI 解析、skinName、state 拆分）不再有任何前缀字符串依赖；
**Scene Builder 层**消费的 `raw.localName`/`raw.tag`/`raw.attributes` 仅作语义与溯源用途，不解析前缀。
若 P1 需要彻底解耦，可在 NormalizedNode 增加派生字段后让 raw 退化为诊断用途。

## 过程中发现并修正的测试问题

- fixture `panel.png` 生成脚本自身有 bug：右侧蓝条画了 10px（x=22 起），与 grid 声明的右缘 8px 不符，
  导致浏览器像素测量被污染。已修正为 x=24 起 8px，并重新生成样本。
- 视觉测量被面板上叠加的其他测试节点干扰 → 复测时隐藏全部兄弟节点后单独测量。
  结论：像素级断言优先用 computed style（`getComputedStyle().borderImageWidth` 权威值），
  截图视觉测量仅作辅助。

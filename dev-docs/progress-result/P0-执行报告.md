### 已知边界（非缺陷，P0 明确范围）

- `text="Label"` 等皮肤内占位文本按 EXML 原样渲染——真实游戏运行时由 Data Binding 注入实际文字，P0 不做运行时注入；
- state 切换（visible.state_xxx / y.state_xxx）只记录不应用，页面底部横幅逐项上报；
- 自定义组件（gdmj:*/ns1:*）按占位容器渲染，子树保留；
- List/Scroller/DataGroup 等容器按占位渲染，子树保留。

## 四、执行过程中的关键修复（详见 dev-docs/experience/）

1. fast-xml-parser v5 preserveOrder 结构与文档示例不符（`?xml` 声明混入顶层）→ tagOf 归一 + 顶层过滤；
2. 图集子图 border-image 九宫格串图（四角压入邻居精灵成彩色条纹）→ 九片背景方案；
3. EUI Group 是坐标系容器，不渲染定位容器导致整组坐标坍缩 → 组渲染为定位 div + measuredSize 测量 + Skin 透明包装层；
4. includeIn 不含默认状态的节点错误显示 → 按 states 首项判定隐藏；
5. 端口 7789 被残留 FairyGUI 服务占用 → 换端口验证（长驻服务记得查进程，CLAUDE.md 规则 6）。
